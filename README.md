# 3D Marble Roulette (Three.js Edition)

기존 2D 마블 룰렛을 **Three.js + Cannon-es(3D 물리 엔진)** 기반으로 재구성하여, 입체적인 3D 트랙, 포토 피니시 슬로우 모션, 네온 블룸(Bloom) 효과, 3D 사운드, 그리고 **참여자 서식 불러오기(`.txt`, `.csv`, `.json`)** 기능을 지원하는 웹 애플리케이션입니다.

## 사용 매뉴얼 (일반 · QR 실시간 참여)
- **온라인 / 인쇄용 전체 매뉴얼**: [manual.html](./manual.html) (게임 화면 상단의 `📖 사용 매뉴얼` 버튼으로도 바로 확인 가능)
- **QR 참여 시 누가 시작하나요?** → **진행자(PC/대형 화면)**가 시작합니다!
  1. **진행자(호스트 · PC)**: `📱 QR 참여방`을 열어 QR을 띄우고, 참여자들이 모두 입장하면 **`🚀 입장 완료! 지금 레이스 시작`**(또는 화면 하단 **`🚀 바로 레이스 시작!`**)을 클릭합니다.
  2. **참여자(스마트폰 QR)**: QR 스캔 → 닉네임·동물 선택 후 입장 → 진행자가 경기를 시작하면 **🎲 랜덤 럭키박스 / ⚡ 대시 부스트 / 🦘 슈퍼 점프 / 📣 응원** 버튼을 눌러 참여합니다.

## 주요 기능
1. **직관적인 아케이드 시작 화면 & 선명한 풀컬러 동물 순위 아이콘**
   - 복잡한 설정 패널을 기본 접힘(`collapsed`)으로 단순화하여, 화면 하단의 **`🚀 바로 레이스 시작!`** 버튼으로 즉시 추첨 가능
   - 실시간 순위표와 우승 결과 창에 16종 동물의 선명한 풀컬러 캐릭터 아이콘 표시
2. **풀바디 3D 동물 캐릭터 & 측면-항공 3/4 시점**
   - 16종의 입체 3D 동물 캐릭터와 위에서 아래로 쏟아져 내려오는 측면-항공 3D 추격 카메라
   - 목표 등수 레이서가 결승선에 근접하면 발동하는 **포토 피니시 슬로우 모션**
   - Web Audio API 기반 실시간 효과음 (충돌, 범퍼, 점프대, 부스터, 우승 팡파레)
2. **QR 실시간 멀티 참여 & 버튼 컨트롤러**
   - 상단 `📱 QR 참여방` 버튼을 눌러 QR 코드를 띄우면, 참여자들이 스마트폰으로 접속해 **닉네임과 동물 캐릭터를 선택해 즉시 입장**할 수 있습니다.
   - 레이스 중 스마트폰 화면에서 **🎲 랜덤 럭키박스 뽑기**, **⚡ 대시 부스트**, **🦘 슈퍼 점프**, **📣 실시간 응원** 버튼을 눌러 자신의 3D 캐릭터에 실시간 물리 효과와 보너스 점수를 줄 수 있습니다.
3. **4가지 580유닛 메가 코스 & 2가지 추첨 방식**
   - 레인보우 메가 오비 / 자이언트 풍차 캐니언 / 터보 하이퍼 범퍼 / 메가 드롭 3단 폭포
   - `🏁 골인 순위` 또는 `⚡ 바운스 점수` 모드 선택 지원
4. **기존 서식 호환 & 구글 시트/파일 불러오기**
   - 구글 시트(Google Sheets) 공유 링크를 붙여넣어 명단 즉시 불러오기 지원
   - 직접 입력: `짱구*2, 철수*3, 유리` (쉼표 또는 줄바꿈 구분, `*숫자` 가중치 지원)
   - 파일 불러오기(드래그 앤 드롭 지원): `.txt`, `.csv`, `.tsv`, `.json`
   - 서식 저장(`.txt`) 및 CSV 양식 다운로드

## GitHub Pages 배포 방법
1. GitHub에서 새 저장소(Repository)를 생성합니다. (예: `marble-roulette-3d`)
2. 이 폴더(`index.html`, `README.md`, `.nojekyll`)의 파일들을 저장소 루트에 업로드(push)합니다.
3. 저장소 상단 **Settings** → 좌측 메뉴 **Pages**로 이동합니다.
4. **Build and deployment**의 Source를 **Deploy from a branch**로 선택하고, Branch를 `main` (폴더: `/ (root)`)으로 설정한 뒤 **Save**를 누릅니다.
5. 1~2분 후 `https://<내_깃허브_아이디>.github.io/<저장소_이름>/` 주소로 접속할 수 있습니다.
